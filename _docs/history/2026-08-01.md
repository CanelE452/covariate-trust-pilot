## 핵심 관찰

1. **budget 제약 자체가 손해다.** ALL_PREMIUM(4 zone 전부 M3) 0.0322가 K=1 oracle
   0.0351보다 좋고 K=2 oracle 0.0321과 사실상 같다. premium-positive rate 0.697이므로
   "누구에게 줄까"보다 "가능하면 다 줘라"가 답이다. budget이 진짜 제약일 때만 선택 문제다.
2. **RANDOM_K도 NO_PREMIUM보다 5.4~10.7% 좋다.** 그래서 "premium 사용 여부"의 이득이
   "선택"의 이득(1% 수준)보다 훨씬 크다. BA3.1이 1.5% 임계에 못 미친 구조적 이유다.
3. **학습된 value predictor가 단순 규칙을 못 이긴다.** P6_RECENT_BASE_ERROR가
   K=1 recovery 52.5% / K=2 62.1%로 P9(44.3% / 55.7%)보다 낫고, week win rate도
   0.58 / 0.64로 P6 우세. BA2 FAIL은 "value model이 필요하다"가 아니라
   "단순 규칙조차 oracle의 절반밖에 못 잡는다"는 뜻이다 — 해석에 주의.
4. headroom 자체는 확실하다: oracle vs random의 week win rate가 K=1·2 모두 **1.000**.
5. premium value 분포는 오른쪽 꼬리가 길다 (mean +0.0075, median +0.0031, skew 3.62).
   LONG_ISLAND가 positive rate 0.750으로 가장 높고 WEST가 0.652로 가장 낮다.
6. WQL selector와 q90 selector의 선택 overlap은 0.51 / 0.55로 꽤 다르지만,
   BA3가 PASS가 아니라 BA4는 실행하지 않았다.
