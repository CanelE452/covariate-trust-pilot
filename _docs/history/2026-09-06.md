### 버그 A (결과 보기 전) — Track F coherence 검출기가 0% 검출

두 개의 독립적인 원인이었다.

1. 상수 level shift 를 input tail 과 target 에 똑같이 더하면
   `B = median(target[:48]) - median(input[-48:])` 에서 offset 이 상쇄돼 B ≈ 0.
   사전등록된 F15 검출기는 A·B 가 모두 1 IQR 이상이고 부호가 같을 것을 요구하므로
   구조적으로 절대 발동할 수 없었다. → shift 를 input 마지막 48 step 에 걸쳐
   ramp 로 넣고 target 에서 이어지게 수정. `coherent_scale` 은 중앙값을 움직이지
   않아 median 기반 검출기가 원리상 볼 수 없으므로 `coherent_trend` 로 대체.
2. 영향 채널 수를 `round(0.3 * C)` 로 계산해 ETTm1 은 7×0.3 → 2채널 = 28.6% 로
   "30% 이상 coherent" 임계를 넘을 수 없었다. → `ceil` 로 변경.

수정 후 sev=4 에서 LEGITIMATE_SHIFT 검출률 ETTm1 73% / Weather 26%,
CLEAN·CORRUPTION 오탐 0%. 두 수정 모두 **결과를 보기 전** 이며 검출기 임계값
(1 IQR, 30%) 자체는 건드리지 않았다.

### 구조적 발견 (테스트에서)

TQNet 은 채널별 instance normalization(RevIN)을 쓰므로 한 채널에 **상수 오프셋**을
더하면 다른 채널 출력이 비트 단위로 동일하다. 즉 순수 level shift 오염은 shared
모델을 통과하지 못한다. spillover 는 형태를 바꾸는 오염에서만 생길 수 있다.
테스트 `T06b`(형태 교란 → cross-channel 경로 존재)와 `T06c`(상수 오프셋 → 흡수)로 고정.
