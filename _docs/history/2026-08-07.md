### torch 설치 (anaconda base) — OMP 충돌과 해소

```
torch 2.13.0+cu126 (2.6GB), CUDA True, RTX 4070 인식
numpy 2.3.5 / pandas 2.3.3 / scipy 1.16.3  — 설치 전후 동일, 기존 패키지 오염 없음
```

`import torch` **단독은 실패**한다:

```
OMP: Error #15: Initializing libiomp5md.dll, but found libiomp5md.dll already initialized.
```

anaconda 의 MKL(`anaconda3/Library/bin/libiomp5md.dll`)과 torch 자체
(`site-packages/torch/lib/libiomp5md.dll`)가 각각 OpenMP 런타임을 들고 온다.

```
import torch          FAIL
import numpy          OK
import numpy, torch   OK     <- numpy 가 먼저면 통과
import torch, numpy   FAIL
```

`posthoc.py` 는 `numpy` -> `pandas` -> `scipy` -> `screen`(torch) 순으로 import 하므로
그대로 통과한다. **`KMP_DUPLICATE_LIB_OK=TRUE` 는 쓰지 않았다** — 그 옵션은 Intel 이
"silently produce incorrect results" 가능성을 경고하는 것이라, 수치 재현을 검증하는
작업에 쓰면 검증 자체가 무의미해진다.

> 주의: torch 를 numpy 보다 먼저 import 하는 새 스크립트를 쓰면 죽는다.
> 근본 해결은 README 의 `.venv` 분리이며, 지금은 import 순서로 회피 중이다.
