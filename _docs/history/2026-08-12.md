## Novelty boundary 정정 — ALR12/Kou13 재검증 + Introduction v5

### 두 가지 정정

```
정정 1  "fixed/controlled marginals 아래 dependence 변화" 를 novelty 에서 제거
        -> experimental control 로 재분류.
        근거 2개 (둘 다 독립):
          (a) [ALR12] 가 이미 할 가능성이 높음 (full text 미확보라 U 로 기록,
              U 를 Y 로 취급 = 우리에게 불리하게 채점)
          (b) 애초에 finding 이 아니라 설계 속성.  frozen source 가 이미 그렇게 다룸:
              claim_ledger_frozen reader chain 1-2 (control 은 step 2 의 전제),
              final_outline_freeze "related work: no novelty claim over the
              correlation literature"
        -> (b) 때문에 LIT-W3 결과와 무관하게 성립.

정정 2  [Kou13] NN-Dual 을 우리 Hurdle 과 동일시하지 않도록 정확화 (full text 확인)
          NN-Rate  단일 linear output = demand rate (direct)
          NN-Dual  두 linear output = z'(size), x'(interval) -> z'/x' (Croston 식 (1))
                   -> inversion bias 발생 -> 회귀로 적합한 계수 c 로 사후 de-bias
          우리 Hurdle  P(Y>0|h) * E[Y|Y>0,h]  = 확률 × 조건부평균, period-indexed,
                   inversion 없음
        즉 비율(ratio) vs 곱(product).  "prior work compares the same two
        representations" / "NN-Dual is a hurdle" 표현 영구 금지 (LIT-W-KOU13).
```

### Figure A 수정 — CV² 를 설계값으로, mean gap 표기 제거

사용자 지적 2건. 둘 다 실재하는 결함이었다.

**1. CV² = 0.12 는 임의값이었다.** 먼저 정의부터 대조했다 — `poster_concept.CV2` 와
SBC 기준 CV² 는 같은 추정량(`(std(positive)/mean(positive))**2, ddof=1`,
`screen.py:121` / `prereg.py:68`)이라 0.12 vs 0.49 비교는 성립한다. [확인]

```
설계값   Stage 1 DGP 는 positive mean 을 lambda 5 / 15 로 교대
         theoretical positive mean 10.0, variance 34.0 (stage1_validity.json)
         -> CV2 = 0.34
기존 toy  CV2 = 0.1222   (ADI 는 4.0 으로 설계와 맞춰뒀는데 CV2 만 안 맞았다)
```

regime 자체는 양쪽 다 intermittent(ADI 4.0 >= 1.32, CV² < 0.49)라 그림의 메시지는
바뀌지 않지만, 심사에서 "설계가 0.34인데 왜 0.12냐"가 나올 수 있다.

크기 수열을 다시 골랐다. 제약 4개를 **동시에** 만족하는 것을 탐색:

```
SIZES = (7, 12, 11, 5, 17, 19, 3, 4, 6, 16)

합 100 (mean 10)            Sum (x-10)^2 = 306  ->  CV2 = 0.3400 정확
lag-1 rho_M = 0 정확        시간추세 corr(t, size) = 0.0000 정확
min = 3                     (1~2 짜리가 있으면 스파이크가 안 보인다)
```

추세까지 0으로 잡은 이유는 원 코드 주석이 이미 적어둔 것과 같다 — 크기가 자체
구조를 가지면 그림이 두 종류의 구조를 동시에 보여주게 된다. lag-1 만 0으로
잡으면 선형 추세는 남을 수 있어 조건을 하나 더 걸었다.

`DESIGN_CV2` 상수와 대조를 `figure_a()` 에 넣어, 수열을 건드려 설계값에서
0.005 이상 벗어나면 ValueError 로 죽는다.

**2. ADI 4.0 vs mean gap 3.89 — 정의상 당연하지만 나란히 두면 안 된다.**

```
ADI       = LENGTH / n_events = 40 / 10   = 4.000
mean gap  = 간격 9개의 평균   = 35 / 9    = 3.889
```

발생 10회면 간격은 9개고, 첫 발생 이전·마지막 발생 이후 구간은 ADI 분자(길이)에는
들어가지만 간격에는 안 들어간다. 둘을 일치시키려면 LENGTH = 10 x 35/9 = 38.9 로
정수가 아니다 — {3,5} 교대를 유지하는 한 일치 불가능하다. [확인]

그래서 **mean gap 표기를 뺐다**. 대신 `same gap multiset` 으로 바꿨다. 통제 사실을
더 강하게 말하는 표현이기도 하다(평균이 같다 < multiset 이 같다).

**3. 부수 수정 2건.** regime 을 그림이 스스로 말하도록 `(intermittent)` 표기 추가
(SBC 사분면을 `SBC_ADI/SBC_CV2` 상수로 판정). rho_M 이 `-0.00` 으로 찍히던 것은
