### x축 라벨 오류 수정 — 요청서 지적이 맞다

원본 라벨은 `Δ = RMSE_Point - RMSE_Hurdle (positive favours Hurdle)` 인데, 각 점은
ΔRMSE 자체가 아니라 **조건 간 대비**다. 이 라벨대로면 d=4 의 -0.028 을 "Point 우위"
로 읽게 되지만 실제 뜻은 "교대 조건이 지속 조건보다 Hurdle advantage 가 컸다" 라
해석이 정반대가 된다.

```
x축      Contrast in ΔRMSE        ΔRMSE = RMSE_Point - RMSE_Hurdle
축 아래  Positive values mean the first-named condition increases the Hurdle
         advantage relative to the reference.
행 라벨  C_neg/C_pos/C_pred/C_sign -> 비교하는 조건명으로 교체
공통조건 ρM = 0 · top three contrasts averaged over d ∈ {4, 8}  (행마다 반복 제거)
유의성   회색 처리 폐기. 모델 색·형태 유지 + CI 0 포함이면 open marker
각주     4개 문장으로 교체, favours -> favors 는 해당 문구 자체가 사라져 무효
```

`iid` 는 쓰지 않았다 — 독립인 것은 간격 과정이지 수요 계열 전체가 아니다.
